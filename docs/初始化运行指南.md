# 颐养年店铺管理 - 初始化运行指南

本指南带你完成从零到在本机（Web 浏览器、Android 手机）运行项目的全过程。

---

## 第一步：安装 Flutter

1. 打开终端，检查是否已安装 Flutter：
   ```bash
   flutter --version
   ```
2. 若未安装，请访问 [flutter.cn](https://flutter.cn/docs/get-started/install/macos) 按 macOS 说明安装，并执行 `flutter doctor` 确保环境正常。

---

## 第二步：创建 Supabase 项目

1. 打开 [supabase.com](https://supabase.com) 并登录（无账号可免费注册）。
2. 点击 **New Project**，填写：
   - **Name**：如 `yiyangnian`
   - **Database Password**：设置一个强密码并记住
   - **Region**：选离你近的区域（如 Singapore）
3. 等待项目创建完成（约 1–2 分钟）。

---

## 第三步：执行数据库迁移

1. 在 Supabase 项目页，左侧点击 **SQL Editor**。
2. 依次执行以下 3 个 SQL 文件（每个文件单独执行一次，点击 Run）：

   **① 建表**  
   打开 `颐养年/docs/supabase_migrations/001_create_tables.sql`，复制全部内容到 SQL Editor，点击 **Run**。

   **② RPC 函数**  
   打开 `颐养年/docs/supabase_migrations/002_rpc_and_functions.sql`，复制全部内容，点击 **Run**。

   **③ RLS 策略**  
   打开 `颐养年/docs/supabase_migrations/003_rls.sql`，复制全部内容，点击 **Run**。  
   若提示 "policy already exists"，可忽略或先删除已有策略后再执行。

   **④ 储值大项选项（可选）**  
   打开 `颐养年/docs/supabase_migrations/005_storage_big_item_options.sql`，复制全部内容，点击 **Run**。  
   用于支持用户自定义储值大项（与储值小项能力对齐）；若未执行，新增/编辑储值时的「储值大项」将无选项可选。

## 第八步：运行项目

### 方式一：使用脚本（推荐）

在 `app` 目录执行：

| 目标 | 命令 |
|------|------|
| **macOS 桌面** | `./scripts/run_with_env.sh macos` |
| **网页（Chrome）** | `./scripts/run_with_env.sh web` |
| **网页快速启动** | `./scripts/run_with_env.sh web-fast`（release 模式，约 10 秒启动） |
| **Android 手机** | `./scripts/run_with_env.sh android` |

### 方式二：手动指定参数

```bash
# macOS
flutter run -d macos --dart-define-from-file=env.json

# 网页
flutter run -d chrome --dart-define-from-file=env.json

# Android（手机需 USB 连接并开启调试）
flutter run -d android --dart-define-from-file=env.json
```

## Android 手机调试说明

1. **开启开发者选项**  
   设置 → 关于手机 → 连续点击「版本号」7 次。

2. **开启 USB 调试**  
   设置 → 系统 → 开发者选项 → 打开「USB 调试」。

3. **连接电脑**  
   用数据线连接手机和 Mac，手机选择「文件传输」或「MTP」。

4. **确认设备**  
   ```bash
   flutter devices
   ```
   列表中应出现你的 Android 设备。

5. **运行**  
   ```bash
   ./scripts/run_with_env.sh android
   ```

## 常见问题

**Q: 提示「未配置 Supabase」**  
A: 检查 `env.json` 是否在 `app` 目录，且 `SUPABASE_URL`、`SUPABASE_ANON_KEY` 已正确填写。

**Q: 登录失败**  
A: 确认 Supabase Authentication 中已创建对应用户，邮箱和密码无误。

**Q: Android 设备未识别**  
A: 确认 USB 调试已开启，数据线支持数据传输，必要时更换数据线或 USB 口。

**Q: Web 运行报错**  
A: 先执行 `flutter run -d chrome` 测试，若仍有问题可尝试 `flutter clean` 后重新 `flutter pub get`。

**Q: Web 登录一直转圈**  
A: 1) 先点击「测试连接」按钮，若失败则说明网络或 Supabase 有问题；2) Supabase 免费版项目 7 天无活动会**自动暂停**，首次请求需等待 30–60 秒唤醒，可在 Dashboard 手动恢复；3) 检查 env.json 的 URL 和 anon key 是否正确；4) 建议不要同时开多个终端调试，避免资源竞争。

**Q: Android 提示 "No devices found with name or id matching 'android'"**  
A: 脚本已更新，会自动检测已连接的 Android 设备。确保手机 USB 连接、开启 USB 调试，运行 `flutter devices` 能看到设备后再执行 `./scripts/run_with_env.sh android`。

**Q: Android 编译失败：clang unsupported option '-arch' for target 'aarch64-none-linux-android'**  
A: 这是 NDK 28 与 macOS 的兼容性问题。项目已配置使用 NDK 26。安装 NDK 26 任选其一：
- **命令行**：`$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager "ndk;26.1.10909125"`
- **Android Studio**：SDK Manager → SDK Tools → 勾选 "Show Package Details" → NDK 下选择 26.1.10909125 安装  
安装后执行 `flutter clean`，再运行 `./scripts/run_with_env.sh android`。
